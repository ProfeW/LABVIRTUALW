Reto de Práctica: Suma de Vectores

Demuestra tu habilidad en operaciones con vectores. Resuelve paso a paso.

Dados los vectores:
\(\vec{A} = (4, -2)\)
\(\vec{B} = (-1, 5)\)
Encuentra el vector resultante \(\vec{R} = \vec{A} + \vec{B}\)

Paso 1: Componente X

Para hallar la componente X resultante (\(R_x\)), debemos sumar la componente X del vector A con la componente X del vector B. La fórmula es \(R_x = A_x + B_x\).

Paso 2: Componente Y

De igual forma, para hallar la componente Y resultante (\(R_y\)), suma la componente Y de A con la componente Y de B. La fórmula es \(R_y = A_y + B_y\).

¡Excelente! Has completado el ejercicio.

El vector resultante es \(\vec{R} = (3, 3)\)
