Reactivo Límite y Estequiometría

Aprende a identificar la sustancia que detiene la reacción y a calcular exactamente cuántos gramos de producto se formarán.

1. Concepto y Metodología (Nivel Décimo)

En cualquier proceso químico industrial, el Reactivo Límite es la sustancia que se agota primero. Al acabarse, la reacción se detiene y determina la cantidad máxima de producto que se puede fabricar. El reactivo que sobra se denomina Reactivo en Exceso.

Para resolver ejercicios completos de estequiometría, agregaremos un paso final a nuestra metodología:

1

Balancear la Ecuación

Ley de conservación de la masa.

2

Calcular Masa Molar (PM)

Suma de masas atómicas (g/mol).

3

Convertir a Moles (n)

n = Masa(g) / PM para todos los reactivos.

4

Dividir entre Coeficiente

Divide los moles entre el número grande de la ecuación.

5

Determinar el Límite

El resultado menor indica cuál es el Reactivo Límite.

6

Cálculo de Gramos Producidos

Usa los moles del Reactivo Límite y aplícales la relación estequiométrica (Regla de 3 con coeficientes) para hallar los moles del producto. Finalmente, multiplícalos por el PM del producto para obtener gramos.

2. Ejercicios Resueltos (Incluyendo Paso 6)

Ejercicio 1: Síntesis del Agua

Se hacen reaccionar 10g de H₂ con 64g de O₂. Determine el reactivo límite y la cantidad en gramos de H₂O que se produce.

Paso 1: Balancear
2H₂ + 1O₂ → 2H₂O
Paso 2: Masa Molar (PM)
H₂ = 2 g/mol | O₂ = 32 g/mol | H₂O = 18 g/mol
Paso 3: Convertir a Moles
n H₂ = 10g / 2 = 5 moles
n O₂ = 64g / 32 = 2 moles
Paso 4: Dividir entre coeficiente
H₂: 5 / 2 = 2.5
O₂: 2 / 1 = 2
El valor menor es 2. El Oxígeno (O₂) es el Reactivo Límite.
Paso 6: Gramos de Producto (H₂O)
1. Relación: Por cada 1 mol de O₂ se producen 2 moles de H₂O.
2. Moles del RL: Tenemos 2 moles reales de O₂.
3. Moles producto: 2 moles O₂ × (2 moles H₂O / 1 mol O₂) = 4 moles H₂O.
4. A Gramos: 4 moles × 18 g/mol = 72 gramos.
Se producen 72 gramos de H₂O.

Ejercicio 2: Formación de Amoníaco

Reaccionan 28g de N₂ con 12g de H₂. Encuentra el reactivo límite y los gramos de NH₃ producidos.

Paso 1: Balancear
1N₂ + 3H₂ → 2NH₃
Paso 2: Masa Molar (PM)
N₂ = 28 g/mol | H₂ = 2 g/mol | NH₃ = 17 g/mol
Paso 3: Convertir a Moles
n N₂ = 28g / 28 = 1 mol
n H₂ = 12g / 2 = 6 moles
Paso 4: Dividir entre coeficiente
N₂: 1 / 1 = 1
H₂: 6 / 3 = 2
El valor menor es 1. El Nitrógeno (N₂) es el Reactivo Límite.
Paso 6: Gramos de Producto (NH₃)
1. Relación: 1 mol N₂ produce 2 moles NH₃.
2. Moles reales producto: 1 mol N₂ (RL) × (2/1) = 2 moles NH₃.
3. A Gramos: 2 moles × 17 g/mol = 34 gramos.
Se producen 34 gramos de NH₃.

Ejercicio 3: Combustión del Metano

Se queman 32g de Metano (CH₄) con 96g de Oxígeno (O₂). Determine el R.L. y los gramos de Dióxido de Carbono (CO₂) generados.

Paso 1: Balancear
1CH₄ + 2O₂ → 1CO₂ + 2H₂O
Paso 2: Masa Molar (PM)
CH₄ = 16 g/mol | O₂ = 32 g/mol | CO₂ = 44 g/mol
Paso 3: Convertir a Moles
n CH₄ = 32g / 16 = 2 moles
n O₂ = 96g / 32 = 3 moles
Paso 4: Dividir entre coeficiente
CH₄: 2 / 1 = 2
O₂: 3 / 2 = 1.5
El valor menor es 1.5. El Oxígeno (O₂) es el Reactivo Límite.
Paso 6: Gramos de Producto (CO₂)
1. Relación: 2 moles O₂ producen 1 mol CO₂.
2. Moles reales de RL: Tenemos 3 moles de O₂.
3. Moles producto: 3 moles O₂ × (1 mol CO₂ / 2 moles O₂) = 1.5 moles CO₂.
4. A Gramos: 1.5 moles × 44 g/mol = 66 gramos.
Se producen 66 gramos de CO₂.

Ejercicio 4: Óxido de Hierro (III)

Se mezclan 112g de Hierro (Fe) con 64g de Oxígeno (O₂). Calcula los gramos de Óxido Férrico (Fe₂O₃) resultantes.

Paso 1: Balancear
4Fe + 3O₂ → 2Fe₂O₃
Paso 2: Masa Molar (PM)
Fe = 56 g/mol | O₂ = 32 g/mol | Fe₂O₃ = 160 g/mol
Paso 3: Convertir a Moles
n Fe = 112g / 56 = 2 moles
n O₂ = 64g / 32 = 2 moles
Paso 4: Dividir entre coeficiente
Fe: 2 / 4 = 0.5
O₂: 2 / 3 = 0.66
El valor menor es 0.5. El Hierro (Fe) es el Reactivo Límite.
Paso 6: Gramos de Producto (Fe₂O₃)
1. Relación: 4 moles Fe producen 2 moles Fe₂O₃.
2. Moles producto: 2 moles Fe (RL) × (2/4) = 1 mol Fe₂O₃.
3. A Gramos: 1 mol × 160 g/mol = 160 gramos.
Se producen 160 gramos de Fe₂O₃.

Ejercicio 5: Cloruro de Aluminio

Reaccionan 54g de Aluminio (Al) con 142g de Cloro (Cl₂). Encuentra los gramos de producto (AlCl₃).

Paso 1: Balancear
2Al + 3Cl₂ → 2AlCl₃
Paso 2: Masa Molar (PM)
Al = 27 g/mol | Cl₂ = 71 g/mol | AlCl₃ = 133.5 g/mol
Paso 3: Convertir a Moles
n Al = 54g / 27 = 2 moles
n Cl₂ = 142g / 71 = 2 moles
Paso 4: Dividir entre coeficiente
Al: 2 / 2 = 1
Cl₂: 2 / 3 = 0.66
El valor menor es 0.66. El Cloro (Cl₂) es el Reactivo Límite.
Paso 6: Gramos de Producto (AlCl₃)
1. Relación: 3 moles Cl₂ producen 2 moles AlCl₃.
2. Moles reales RL: 2 moles de Cl₂.
3. Moles producto: 2 moles Cl₂ × (2/3) = 1.33 moles AlCl₃.
4. A Gramos: 1.33 moles × 133.5 g/mol = 177.5 gramos.
Se producen 177.5 gramos de AlCl₃.
